# UX_TEST.md — 15-minute hallway usability test (5 people)

> Run by the team, not the agent. Results stay **TBD** until the test has actually happened. Never invent them.

## Before you start
- Use people who have not seen Kairos (classmates are fine). Aim for 5.
- Use a laptop with the Assistant mode open, Inspector hidden, and sound on.
- Read the consent line: *"We're testing the app, not you. There are no wrong answers. We'll write down what you say but not your name. You can stop at any time."*

## Part 1 — First impression (20 seconds)
Press **Play the demo** and let Story mode run for 20 seconds. Then ask: **"What do you think this is doing?"**
Write down their words exactly. Count it as "understood" if they say something like *"it answers while I'm talking"* or *"it's searching before I finish"*.

## Part 2 — Three tasks (time each one; note success, hesitations and quotes)
*These tasks match the placeholder corpus. When the real corpus arrives, rewrite them with the same three shapes (compound question, late detail, reformat + find a source).*
1. **Ask a compound question by voice:** "Ask it where you could hold a workshop in Pune for 30 people, and what the cancellation and catering rules are."
2. **Add a late detail:** "Now tell it that it's actually for 45 people." (Watch: do they notice only part of the answer changed?)
3. **Get it shorter and check a source:** "Make the answer into bullets, then find where the cancellation rule came from."

## Part 3 — System Usability Scale (SUS)
Ask them to rate each statement from 1 (strongly disagree) to 5 (strongly agree):
1. I think that I would like to use this system frequently.
2. I found the system unnecessarily complex.
3. I thought the system was easy to use.
4. I think that I would need the support of a technical person to be able to use this system.
5. I found the various functions in this system were well integrated.
6. I thought there was too much inconsistency in this system.
7. I would imagine that most people would learn to use this system very quickly.
8. I found the system very cumbersome to use.
9. I felt very confident using the system.
10. I needed to learn a lot of things before I could get going with this system.

**Scoring:** for odd items subtract 1 from the answer; for even items subtract the answer from 5. Add the ten results and multiply by 2.5. That person's SUS score is 0–100. Report the mean with n.
